Study Planner Mobile Application UI/UX Design

## 📌 Project Overview
This project is a Study Planner Mobile Application UI/UX design created using Figma. The application is designed to help students organize study schedules, manage tasks, and improve productivity through a clean and modern mobile interface.

The project focuses on user-centered design principles, typography, color balance, layout organization, and interactive mobile prototyping.

---

## 🎯 Objectives
- Improve student productivity
- Simplify study management
- Create an attractive mobile interface
- Provide smooth navigation experience
- Design modern mobile UI screens
